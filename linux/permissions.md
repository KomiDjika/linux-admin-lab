# Permissions

What is chmod : help change the rights user or groups have over files & directories

What is chown : help change the user or groups that permission to access files & directories

What does rwx mean : read, write, execute. r = 4 ; w = 2 ; x = 1

What is sudo : it's used to tell the system that i want to use admin previlages(root account) to execute the next command. Always requires admin log in
